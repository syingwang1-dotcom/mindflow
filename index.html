小悟 · 深度复盘

把你在心流伴侣中记录的所有思绪交给「小悟」，它会帮你发现模式、给出反馈、提出追问。
使用方法：
1. 点「 复制 Prompt（含记录）」一步到位，或先点「 复制全部记录」
2. 找一个有长记忆能力的 AI（推荐 Claude Projects 或 ChatGPT）
3. 把内容粘贴进去，小悟会自动生成深度复盘
提示：如果在 Project 中，可将 Prompt 放进 System Instructions，日后只粘贴记录即可
